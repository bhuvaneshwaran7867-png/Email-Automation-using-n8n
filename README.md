# n8n Email Automation

## Overview
This is a demo project developed using n8n to automate Gmail notifications from Excel data.

## Workflow
Excel Data Source
->
n8n Workflow Processing
->
Gmail Node
->
Automated Email Delivery

## Features
- Excel data integration
- Gmail automation
- Workflow automation using n8n
- Error handling and debugging
- Team collaboration

## Tools Used
- n8n
- Gmail
- Microsoft Excel

## Learning Outcomes
- Workflow design
- Node configuration
- Troubleshooting automation workflows
- Team collaboration
